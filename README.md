# EvoCAD Research Review

Read-only CAD research archive grouped by Harness, Model and experiment.

This release contains 20 native geometry bundles (108 run records). The original
17 bundles (78 records), six Astra execution archives and five Kimi trace pages
are retained. DeepSeek CAD80 r9 adds three native geometry bundles, each with
10 records, in the same Harness / Model / Experiment browser as other models.
It includes 18 interactive candidate meshes, 50 candidate previews, 11 generated
source files, 26 saved model statements, 10 STEP candidates and 9 assembly-pose
JSON candidates. Ten frozen text queries and 28 attributed T-LESS input photos
are included; remaining task descriptions are identified editorial summaries.
The previous separate DeepSeek HTML routes now redirect to this shared browser.
Preview images
are identified as post-run renders or historical evaluator candidate renders;
they are not model-produced images or new scoring evidence. Source files are
inert text display copies with local dependency paths redacted, not a packaged
reproduction environment. Per-file notices document provenance and changes.
The separate drawing-understanding application is removed from this release.

Diagnostic measures retain their original scope; complete task acceptance and
unreported model backend details remain unknown. Original evidence hashes are
retained as provenance where available. This site contains redacted derivatives,
not byte-identical copies of raw provider logs. Private reasoning, credentials,
environment configuration and raw provider logs are excluded.

Third-party drawings retain their original rights. Publication does not grant a
new redistribution license. Candidate annotations are not expert-certified
ground truth.

DeepSeek reference geometry update: 18 source-pinned reference meshes now
appear beside the archived candidates. References follow the actual historical
evaluation versions, including repaired geometry where the receipt identifies
it. Photo-scored references are visual context, not newly computed 3D scores.
Only verified shared coordinate frames enable overlay; no new fit or scoring
is performed. The published historical references are disclosed review data,
not an unexposed future blind-test edition. Per-case notices bind source and
license information. All earlier candidate assets, scores and statements stay
unchanged.

T02 now provides an independent task-formula working-flank diagnostic view.
Only axial translation and rotation about the axis are permitted. The analytic
flanks are an open surface, not a replacement whole-solid reference. The old
reference and candidate coordinates, legacy fixed-frame score and all archived
evidence remain accessible. Finite geometric samples are not full task acceptance.
